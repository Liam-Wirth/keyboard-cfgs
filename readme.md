# Keyboard Configs

Pretty simple stuff, just a place to host maps and things I set for keyboards I get/try out.

Now that I have "adult money" I get to start spending some of it on stupid things that I like, such as vintage computing hardware, or certain keyboards.

I'm not the hugest into like modern MX keyboards, I do think it's kinda boring with them after a while, but I am into alot of the unique/esoteric boards like ones with weird key layouts (still qwerty but changes like ortholinear or split) things like that. Also like vintage boards :)

## layout description
- `karabiner.json`
on MacOS they make it a pain to remap things, so like the rest of things in the ecosystem you have to download some silly app to get functionality that runs, I use karabiner elements.
I'm at a point where capslock -> escape is basically mandatory for me, but karabiner also lets me sanely remap printscreen for external keyboards so i'm backing up my whole config for that here.
